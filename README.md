<details>
<summary><b>⚛️ QSafe BB84 — Quantum-Safe Key Distribution System</b></summary>

<br/>

An implementation and simulation of the **BB84 Quantum Key Distribution (QKD) protocol** — the foundational algorithm for quantum-safe cryptography. This project implements the full BB84 handshake in TypeScript with a visual simulation layer, enabling quantum-secure key exchange that is theoretically immune to eavesdropping.

| Attribute | Details |
|-----------|---------|
| **Stack** | TypeScript · JavaScript · Quantum Simulation Libraries |
| **Domain** | Quantum Cryptography · Post-Quantum Security |
| **Protocol** | BB84 QKD — Polarization-based qubit encoding & basis reconciliation |
| **Security** | Eavesdropping detection via QBER (Quantum Bit Error Rate) analysis |
| **Impact** | Foundational implementation of a post-quantum cryptographic primitive |
| **Repository** | [![GitHub](https://img.shields.io/badge/View%20Repo-qsafe_bb84-6D28D9?style=flat-square&logo=github)](https://github.com/Neha-george/qsafe_bb84) |

The system simulates Alice-to-Bob quantum channel communication, basis selection, key sifting, and error estimation. The TypeScript implementation makes the quantum protocol accessible for web-based educational and research applications, bridging classical software engineering with post-quantum security concepts.

</details>
